# B-2: 정책 시뮬레이터

임의의 할인 정책표를 입력받아 **가상 매장에서 2주 장사를 재현**하고,
판매량·매출·마진·폐기량·이익 성적표를 산출합니다.
A-2가 생성한 후보 정책을 평가하여 A-3의 선택 근거를 제공합니다.

> 본 문서는 v2(피드백 반영판) 코랩 정식 실행 결과 기준입니다.

## 1. 존재 이유

A-2가 할인 후보를 잘 만들어도, 각 후보의 결과를 미리 볼 수 없으면 A-3는 고를 수 없습니다.
현실 매장에서 정책을 실험하는 것은 손실 위험이 크므로, 가상 매장에서 대신 실험합니다.

## 2. B-1 시뮬레이션과의 차이

| | B-1 시뮬레이션 | B-2 시뮬레이션 |
|---|---|---|
| 정책 | 기존 정책 고정 | **임의의 정책표 입력 가능** |
| 재고 | 매일 기록된 스냅샷을 읽음 | **재고를 직접 굴림** (입고 → 판매 차감 → 만료 폐기) |
| 폐기량 | 계산 불가 | **계산 가능** |
| 시간 격자 | 시간대 5구간 | 1시간 13구간 (10~22시) |
| 역할 | 두뇌 제작 + 기준결과 산출 | 정책 실험실 |

폐기 감축이 프로젝트의 최종 목표이므로, **폐기를 계산할 수 있게 된 것**이 B-2의 존재 가치입니다.
이를 위해 재고를 "읽기"에서 "굴리기"로 전환한 것이 구조적 핵심입니다.

## 3. 입력

| 입력 | 출처 | 형태 |
|---|---|---|
| 구매확률 모델 + 보정계수 | B-1 | `b1_models.joblib`, `b1_sim_calibration.joblib` |
| 후보 할인 정책표 | A-2 | 아래 스키마의 표 |
| 정가 기본수요 (P10·P50·P90) | A-1 | **규모 보정 기준값으로만 사용** |

> A-1의 출력은 계산식 안에 곱해 넣지 않습니다(이중 계산 방지 합의).

### 정책표 스키마 (A-2와의 계약)

```
store_id | product_id | date | hour(-1=전시간) | dte_min | dte_max | discount_rate(0~40 정수%)
```

"잔여 유통기한이 `dte_min`~`dte_max`인 로트에, 해당 시각부터 이 할인율 적용"을 의미합니다.

예시: `(S01, P001, 12/3, 18, 0, 1, 40)`
→ 12월 3일 18시부터 임박 로트(기한 0~1일)를 40% 할인

표에 없는 조합은 자동으로 0%가 적용됩니다.
v2부터 기존 정책도 그날 첫 할인 판매 시각부터 활성화되도록 시간을 복원해 재현합니다.

## 4. 내부 동작: 가상 매장의 하루

**아침** — 그날 입고 예정 로트가 매대에 추가됩니다.
발주는 실제 기록을 따릅니다(할인 정책이 발주까지 바꾸지 않는다는 가정).
초기·입고 재고는 사중 자격조건(미품절·비만료·잔여기한≥0·가용>0)을 통과한 것만 진열됩니다.

**매 시간 (10~22시)**

1. 정책표를 조회해 로트별 할인율 결정
2. 같은 상품이라도 할인 임박 로트와 정가 신선 로트는 별개 오퍼로 진열
3. 해당 시각 실제 방문객 수만큼 가상 손님 등장 (단골 가중)
4. 손님마다 후보 4개 노출 — 재고 많은 오퍼가 더 자주, 중복 없이 (B-1 v3과 동일 규칙)
5. B-1 모델이 선택확률 계산, 주사위로 구매 결정
6. 구매 시 수량모델이 개수를 결정하고 임박 로트부터 재고 차감 (품절 시 구매 포기)
7. 구매한 손님의 기억 갱신

**하루 마감** — 유통기한이 종료된 로트의 잔여분을 폐기로 집계(수량·원가손실),
나머지는 기한 −1로 이월. 이를 14일 × 다회 반복(몬테카를로)하여 평균±흔들림을 산출합니다.

## 5. 구매수량 모델

당초 계획은 Poisson / Negative Binomial이었으나, 진단 결과
수량의 분산÷평균이 **0.28**로 1보다 크게 작아(과소산포) 두 분포의 가정과 정반대였습니다.
0개 구매 행도 없어 Zero-inflated 계열도 해당되지 않았습니다.

따라서 "1~5개 중 하나 고르기" 문제로 재정의하고 두 방식을 비교했습니다.

- **경험분포** — 카테고리×할인여부별 과거 비율 그대로
- **다항 로짓** — 가구유형·연령·소득을 반영하는 다범주 로지스틱 회귀

v1 데이터에서는 가구별 수량 차이가 없어 경험분포가 우세했으나,
갱신 데이터에서 가구특성 신호가 발생하여 **다항 로짓이 역전, v2에서 채택**했습니다.
시뮬레이터가 채택 모델로 실제 분기하도록 버그도 함께 수정했습니다.

## 6. 눈금 맞추기: 2단 강도보정

### 개발 중 잡은 가장 중요한 버그

초기 실행에서 기존 정책과 무할인의 결과가 완전히 동일했습니다.
원인은 가상 수요가 공급 총량을 초과해 **어떤 정책이든 전량 매진**되었기 때문입니다.
다 팔리면 정책이 무엇이든 결과가 같으므로, 정책 비교 도구로서 무의미해집니다.

> 교훈: 시뮬레이터는 "그럴듯해 보이는가"가 아니라
> **"정책 간 차이를 만들 수 있는가"** 로 검증해야 합니다.

### 해결책

- **1단** — 전역 배율 G를 이분탐색으로 찾아 검증기간 총판매량을 실제에 맞춤 (총량 담당)
- **2단** — 시간×카테고리 IPF(반복 비례 맞춤, 평균 1로 정규화)로
  "언제·무엇이 팔리는지" 모양을 맞춤 (모양 담당)

v2에서 G가 **0.505 → 0.870** 으로 1에 크게 접근했습니다.
자격조건·노출규칙 개선으로 사후 보정 의존도가 낮아졌다는 신호입니다.

### 탄력성 훅

채택된 B-1 모델은 할인 반응이 +1.5%로 지나치게 평평합니다(할인-임박 교란).
이대로면 "어떤 할인도 효과 없음"으로 왜곡되므로,
확률의 odds에 `exp(k × 할인율)`을 곱하는 손잡이를 두었습니다.

| 모드 | k | 근거 |
|---|---|---|
| `off` | 0 | 모델 그대로 |
| `mid` | 0.408 | 데이터에서 측정한 조건부 상승폭 +18%에 맞춘 중간 가정 |
| `upper` | 0.624 | 상단 가정 +28% |

인과 추정이 아닌 **가정 시나리오**이며, 모든 후보에 동일한 k를 적용하므로
비교의 공정성은 유지됩니다. 결론에는 반드시 3모드 민감도를 함께 제시합니다.

## 7. 검증 (기존 정책 재현, 12/1~14)

```
판매수량  6,202 / 6,436 = 0.964      시간별 패턴 상관 0.928
폐기수량    776 /   999 = 0.777      일별 상관 0.700
보정: G=0.870 + 시간×카테고리 IPF
```

수량과 시간 패턴은 강하게 재현됩니다.
폐기 재현(0.78)과 일별 상관(0.70)은 이전 버전보다 하락했는데,
기존 정책의 시간 복원으로 오전 할인 노출이 감소한 영향으로 추정되며 잔여 과제로 명시합니다.

사용 원칙은 B-1과 동일합니다. **총량 예언이 아니라 정책 간 비교 도구**이며,
모든 후보가 같은 눈금 위에서 경쟁하므로 비교는 유효합니다.

|---|---|---|---|---|---|
| 기존정책 | 6,280 | 5,115만 | 712 | -84만 | 기준 |
| 무할인 | 6,739 | 6,048만 | 301 | +867만 | +951만 |

### "무할인이 최선"을 믿으면 안 되는 이유

이는 사업적 결론이 아니라 **이 합성데이터의 성질**입니다.
데이터에 할인의 수요 진작 효과가 거의 기록되어 있지 않고(교란으로 학습 자체가 어려움)
원가율이 높아, 할인이 마진만 깎는 구조입니다.

탄력성을 올리면 할인 정책의 폐기·이익이 개선되는 민감도가 그 증거이며,
데이터팀에 교란 완화 개선을 요청한 상태입니다.
실데이터가 확보되면 이 표의 순위는 바뀔 수 있으며,
그때 판단할 수 있도록 **민감도 축을 남겨둔 것이 이 데모의 목적**입니다.

### 민감도 (A-3가 함께 봐야 할 표)

```
[탄력성 가정]  off: 폐기 610 / 이익 -202만
               mid: 폐기 530 / 이익 -108만
             upper: 폐기 452 / 이익 -126만

[수요 시나리오]  P10(×0.8): 폐기 917 / -214만
                 P50      : 폐기 700 / -106만
                 P90(×1.2): 폐기 509 /  +87만
```

탄력성이 커질수록 폐기가 줄고, 수요 수준에 따라 같은 정책의 손익이 역전됩니다.
이것이 A-3가 기대 이익만이 아니라 **최악 수요(P10)의 폐기까지 보는
위험회피 목적함수**를 사용해야 하는 근거입니다.

시나리오 배율(0.8/1.0/1.2)은 현재 자리표시이며,
A-1 안정화 후 실제 분위수 비율로 교체하는 연결 지점(`anchor_scale`)이 마련되어 있습니다.

## 9. 남은 한계

1. **품절 시 대체구매 미구현** — 선택한 할인 로트가 소진되면 구매 포기로 처리.
   할인비중 과대와 폐기 재현 하락의 주요 원인 후보로, 고도화 1순위
2. **폐기 재현율 0.78 · 일별 상관 0.70** — 시간 복원의 트레이드오프, 원인 분석 예정
3. **이익이 음수로 표시** — 로트 원가 기준 마진 정의 때문(실제 회계와 상이 가능).
   정책 간 차이 비교가 목적
4. **발주 불변 가정** — 할인 정책이 발주량을 바꾸는 효과는 범위 밖
