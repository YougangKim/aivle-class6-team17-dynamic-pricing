# B-1: 가상소비자 구매확률 모델

신선식품 동적 할인 시스템에서 **손님 한 명이 특정 상품 상태를 보고 구매할 확률**을
예측하는 모델입니다. B-2 정책 시뮬레이터의 두뇌 역할을 합니다.

> 본 문서는 v3(피드백 반영판) 코랩 정식 실행 결과 기준입니다.

## 1. 역할과 산출물

| 산출물 | 내용 | 받는 곳 |
|---|---|---|
| 구매확률 모델 | "이 손님이 이 상품 상태를 보면 살 확률" 계산기 | B-2 |
| 기존 할인 규칙표 | 현재 매장 규칙(잔여기한별 할인율)의 추출본 | A-2 |
| 기준결과 | 기존 정책으로 2주 장사했을 때의 판매·매출 재현 | A-3 |

### 확률의 정확한 정의

B-1이 산출하는 값은 **"후보 오퍼 내 선택확률"** 입니다.
손님이 매대에서 실제로 무엇을 봤는지(노출 데이터)는 기록에 없으므로,
"후보 4개가 눈에 띄었다고 가정했을 때 그중 이것을 고를 확률"로 정의됩니다.
절대적 구매확률로 해석해서는 안 되며, 총량이 필요한 경우 별도의 규모 보정을 거칩니다.

## 2. 데이터

합성 데이터 CSV 8종을 사용합니다.

- `visitor` (방문 기록 63만 건) — 누가 언제 왔는가
- `receipt` (구매 기록 12만 건) — 무엇을 샀는가
- `inventory` (재고 스냅샷 7.5만 행) — 그날 매대 상태
- `customer` (가상 손님 1만 명) — 고객 특성
- 그 외 `product`, `store`, `calendar`, `store_visitor_profile`

영수증에 재고 일련번호가 기록되어 있어 "우유를 샀다"가 아니라
"유통기한 1일 남고 30% 할인 중이던 우유를 샀다"까지 식별됩니다.
할인·신선도 반응을 학습할 수 있는 근거가 여기에 있습니다.

## 3. 피처 (35개)

| 묶음 | 개수 | 예시 |
|---|---|---|
| 상품 상태 | 10 | 카테고리, 정가, 할인율, 잔여기한, 신선도점수 |
| 손님 특성 | 7 | 연령대, 가구유형, 가격민감도, 선호 카테고리 |
| 손님의 기억 | 6 | 카테고리·상품별 기억점수, 마지막 구매 후 경과일 |
| 시간·장소 | 8 | 시간대, 요일, 공휴일, 계절, 매장유형 |
| 조합·맥락 | 4+ | 가격민감도×할인율, 할인×임박, 정가 신선 대안 존재 |

### 기억(memory stream)

논문 *Generative Agents*의 개념을 적용한 자체 설계 부분입니다.
손님이 구매할 때마다 해당 카테고리·상품의 기억점수에 1을 더하고,
하루 경과마다 0.97배로 감쇠시킵니다(한 달 뒤 약 40%).
시뮬레이션 중에도 실시간 갱신되어 다음 날 선택에 영향을 줍니다.

## 4. 학습 설계

**네거티브 샘플링** — 구매 기록만 학습하면 "사람은 항상 산다"고 오해하므로,
방문 한 건마다 그날 매대에 있었으나 구매하지 않은 상품 4개를 오답 사례로 추가합니다.
절반은 해당 손님의 선호 카테고리에서 추출합니다.
v3부터 **재고량 비례 + 비복원** 표집을 적용했습니다.

**시간순 분할** — 학습(~9/30) / 검증(10/1~11/15) / 시험(11/16~12/31).
무작위 분할은 미래로 배워 과거를 맞히는 누수가 되므로 사용하지 않습니다.
모델 선정 근거는 검증 구간에서, 최종 성적만 시험 구간에서 측정합니다.

## 5. 모델 4종 비교

| 코드명 | 정식 명칭 | 원리 |
|---|---|---|
| `rule` | 조건부 확률표 (자체 구현) | 카테고리×할인구간×민감도 그룹별 과거 구매율 조회, 축소 추정 |
| `lr` | Logistic Regression | 35개 피처의 선형 결합, 업계 표준 기준선 |
| `cbcal` | CatBoost + Isotonic Calibration | 부스팅 결정나무 + 검증 데이터 기반 확률 후교정 |
| `mono` | Monotonic LightGBM | 동일 계열 + "할인율에 대해 예측 비감소" 단조 제약 |

### 성적표 (시험 구간)

| 모델 | AUC | LogLoss | Brier | ECE |
|---|---|---|---|---|
| rule | 0.5947 | 0.1798 | 0.0424 | 0.0008 |
| lr | 0.8045 | 0.1486 | 0.0367 | 0.0082 |
| cbcal | **0.8600** | 0.1265 | 0.0317 | 0.0010 |
| mono | 0.8427 | 0.1412 | 0.0366 | 0.0013 |

네 모델 모두 ECE 0.01 이하로, 확률을 액면가 그대로 시뮬레이션에 투입할 수 있습니다.

## 6. 최종 채택: Monotonic LightGBM

성능 1위는 CatBoost이나 **채택하지 않았습니다.**

### 할인반응곡선 (임박 상황 고정, 할인율만 변화)

| 할인율 | rule | lr | cbcal | mono |
|---|---|---|---|---|
| 0% | 0.0369 | 0.1879 | 0.7067 | 0.0713 |
| 20% | 0.0461 | 0.0612 | 0.0553 | 0.0719 |
| 40% | 0.0574 | 0.0165 | 0.0574 | 0.0724 |

단조성: rule ○ / lr ✗(역방향) / cbcal ✗(0%에서 0.71 후 급락) / **mono ○**

### 왜 성능 1등이 탈락했는가

이 데이터에서 할인은 유통기한 임박 상품에만 부여됩니다.
따라서 데이터상으로는 "할인 상품 = 안 팔리는 상품"으로 보이지만,
안 팔린 실제 원인은 할인이 아니라 임박입니다(교란).
학습력이 강한 CatBoost는 이 교락 구조까지 학습해
"할인하면 덜 팔린다"고 답하며, 이 모델로 최적 할인을 탐색하면
"할인하지 마라"는 정반대 결론이 도출됩니다.

**예측을 잘하는 모델과, 조건을 바꿔 물어도 되는 모델은 다릅니다.**

mono의 한계도 함께 명시합니다. 반응 폭이 +1.5%로 지나치게 평평하며
(단조 제약은 방향만 보장하고 크기는 보장하지 않음),
데이터에서 직접 측정한 조건부 상승폭은 약 +18%입니다.
이 차이는 B-2의 탄력성 보정 손잡이로 보완합니다.

## 7. 시뮬레이션 검증

채택 모델로 가상 손님 1만 명을 움직여 12/1~14 기간을 20회 반복 재현합니다(몬테카를로).

```
실제  qty 6,436 / rev 5,430만원
시뮬  qty 5,337(±102) / rev 4,334만원
수량 재현율 0.829 · 매출 재현율 0.798 · 일별 패턴 상관 0.891
할인판매 비중: 실제 29.5% vs 시뮬 36.9%
```

| 버전 | 수량 재현율 | 매출 재현율 | 할인비중 |
|---|---|---|---|
| v1 초기 | 0.701 | 0.681 | 47.7% |
| v2 데이터 갱신 | 0.815 | 0.756 | 37.9% |
| **v3 피드백 반영** | **0.829** | **0.798** | **36.9%** |

**올바른 사용법** — 총량을 맞히는 예언 도구가 아니라,
같은 조건에서 정책 A와 B 중 무엇이 나은지 비교하는 실험 도구입니다.
두 정책이 같은 비율로 축소되므로 비교 목적에는 문제가 없으며,
일별 패턴 상관 0.89가 "언제 많이/적게 팔리는지"의 구조 학습을 보여줍니다.

## 8. 남은 한계

1. **할인비중 +7.4%p 격차** — 선택한 할인 로트가 품절이면 구매 포기로 처리되며,
   옆의 정가 로트로 갈아타는 대체구매가 미구현. B-2 고도화 1순위
2. **mono 반응 평평** — 근본 원인은 데이터의 할인-임박 교락.
   데이터팀에 "신선 로트에도 프로모션 할인 소량 부여" 개선 요청 완료
3. **노출 데이터 부재** — 확률은 선택확률로 제한 해석
4. **합성데이터 기반** — 절대 수치보다 방법론의 재현 가능성이 성과
